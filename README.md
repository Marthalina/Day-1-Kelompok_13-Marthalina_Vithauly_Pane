- Dokumentasi Kegiatan Workshop (Day 1)
1. Rangkuman Materi
Selama pelaksanaan Day 1, terdapat empat fokus materi utama yang dipelajari:
A. Rencana Strategis JTIK (Roadmap 2026–2030)
- Arah pengembangan JTIK berfokus pada pendidikan vokasi, penguatan SDM, kemitraan industri, sarana infrastruktur, dan inkubator bisnis
- Visi utama jurusan adalah menjadi jurusan bertaraf internasional yang menghasilkan lulusan unggul, adaptif, dan berdaya saing
- Pelaksanaan tridarma (pendidikan vokasi, riset, dan pengabdian) akan didukung oleh sistem tata kelola administrasi berbasis digital

B. Kurikulum Merdeka (MBKM) & MSIB
- Program MBKM memberikan hak belajar di luar program studi hingga 2 semester yang dapat dikonversi menjadi maksimal 20 SKS per semesternya
- Tersedia 8 bentuk kegiatan pembelajaran, salah satu program unggulannya adalah MSIB (Magang dan Studi Independen Bersertifikat) yang memberikan pengalaman proyek nyata bersama mentor dari industri
- Metode pembelajaran yang ditekankan berfokus pada keaktifan mahasiswa, seperti Project-Based Learning (PjBL), Problem-Based Learning(PBL), dan Case-Based Learning (CBL)

C. Tata Tertib & Prosedur Laboratorium TIK
- Peminjaman alat laboratorium memerlukan pengisian formulir, tanda tangan Kepala Laboratorium (Kalab), dan penyerahan KTM sebagai jaminan apabila alat dibawa pulang
- Aturan kedisiplinan mewajibkan mahasiswa berpakaian rapi, memakai sepatu tertutup, dan khusus bagi pria wajib memiliki potongan rambut pendek rapi (tidak melebihi kerah dan tidak menutupi telinga)
- Dilarang membawa makanan, minuman, dan merokok di area gedung kuliah, ruang kelas, maupun laboratorium
- Terdapat alur sanksi yang jelas untuk pelanggaran, dimulai dari peringatan lisan hingga sanksi terberat berupa pemberhentian studi

D. Version Control (Git, GitHub) & Prompt Engineering
- Git adalah sistem version control terdistribusi yang berjalan secara lokal di komputer untuk melacak setiap perubahan file
- GitHub adalah platform berbasis web untuk menyimpan repository secara online dan mempermudah kolaborasi jarak jauh
- Siklus dasar Git melibatkan Working Directory, pemindahan file ke Staging Area (git add), dan penyimpanan perubahan ke Repository (git commit)
- Prompt Engineering: Agar model AI memberikan respons yang presisi, prompt harus dirancang dengan struktur Role (Peran), Task(Tugas), Context(Konteks), dan Format (Bentuk Keluaran)
